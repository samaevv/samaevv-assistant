# samaevv-assistant · Джарвіс  (v0.2.0)

Український голосовий асистент для Linux (Wayland і X11): слово активації «Джарвіс», розпізнавання мови на ПК, свої команди та плагіни, центр керування.
Найкраще перевірено на Omarchy (Arch + Hyprland). Інші дистрибутиви й середовища підтримані, але ще не перевірені: докладна таблиця в [SUPPORT.md](SUPPORT.md).
Усе розпізнавання й робота з камерою відбуваються локально. Для складних питань потрібен «мозок»: Claude Code або Codex (твій власний акаунт).

## Встановлення (одна команда)

```bash
curl -fsSL https://raw.githubusercontent.com/samaevv/samaevv-assistant/main/get.sh | bash
```

Установник сам: поставить потрібні пакети (попросить `sudo`), створить середовище Python, завантажить моделі (кілька хвилин), знайде Claude або Codex і запустить Джарвіса.
Скажи: **«Джарвіс»**.

### Через AUR (якщо пакет опубліковано)
```bash
yay -S samaevv-assistant
samaevv-assistant-setup        # без sudo: створює середовище й запускає
```

## Оновлення
Повтори команду встановлення. Твої налаштування, нотатки й пам'ять не змінюються.

## Видалення
```bash
~/.voice-claude/../.local/bin/jarvis-doctor    # діагностика, якщо щось не працює
```
Повне видалення: запусти `install.sh --uninstall` із розпакованого архіву (дані лишаються в `~/.voice-claude`).

## Що всередині
- Слух: Vosk (слово-пробудження) + Whisper (на відеокарті NVIDIA в рази швидше).
- Голос: Microsoft Edge TTS (безкоштовно) або свій ключ ElevenLabs.
- Плагіни: погода, нотатки Obsidian, радіо, нагадування, буфер, OCR та інші (меню «Магазин»).
- Центр керування: `jarvis-panel` (у браузері, скрізь) або `Super+Shift+J` (Omarchy).
- Жести й камера: за бажанням, локально.

## Вимоги
- Linux: Arch/Omarchy, Ubuntu/Debian/Mint, Fedora, openSUSE (установник сам розпізнає менеджер пакетів).
- Графічне середовище: Hyprland, Sway, будь-яке X11, KDE, GNOME (на GNOME Wayland керування вікнами недоступне, решта працює).
- Звук: PipeWire або PulseAudio. Відеокарта NVIDIA бажана, але не обов'язкова.

## Центр керування
Команда `jarvis-panel` відкриває його в браузері на будь-якій системі (локально, захищено токеном). На Omarchy є ще вбудована панель `Super+Shift+J`.

## Приватність
У пакеті немає жодних особистих даних автора. Усе, що Джарвіс про тебе дізнається (нотатки, історія, налаштування), лежить лише в `~/.voice-claude` на твоєму ПК.

## Для автора: як опублікувати
1. `gh auth login`
2. `./publish.sh` (створить репозиторій і випуск із тарболами)
3. За бажанням завантаж `PKGBUILD` в AUR (https://aur.archlinux.org).
